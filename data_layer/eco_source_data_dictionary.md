# Eco-Source Optimizer — Dataset Data Dictionary

Companion to `eco_source_telemetry.csv` (generated by
`generate_eco_source_dataset.py`). Load-ready for the Week-2 MVP backend and
the rule-based optimizer.

## System assumptions

| Parameter | Value |
|-----------|-------|
| Battery bank | 24 V DC nominal, LFP (Lithium Iron Phosphate), 8S configuration |
| Pack capacity | 300 Ah usable (~7.68 kWh @ 25.6 V) |
| Internal resistance | 0.010 Ω (used for terminal-voltage sag/rise) |
| C-rate limit | 0.5C → ±150 A magnitude cap |
| Charge power cap | 3.0 kW (inverter/charger) |
| Region / grid | Pakistan, 50 Hz nominal, 230 V single-phase site feed |
| Timezone | Asia/Karachi (UTC+05:00), ISO-8601 timestamps |
| Sampling | 15-minute interval, 30 days → 2,880 rows/site |
| Sites | SITE_001..SITE_004 → 11,520 rows total |

## 24 V LFP (8S) OCV vs SoC curve (held constant across all rows)

| SoC % | 0 | 10 | 20 | 40 | 60 | 80 | 95 | 100 |
|-------|---|----|----|----|----|----|----|-----|
| OCV V | 20.0 | 24.8 | 25.6 | 26.0 | 26.4 | 26.6 | 27.2 | 29.2 |

Terminal voltage = OCV(SoC) + I × 0.010 Ω, clamped to [20.0, 29.2] V.
- 20.0 V = 0% safe cutoff
- 25.6 V = nominal mid-range
- 29.2 V = 100% full/float

## Safety thresholds (align with `data_layer/safety_thresholds.yaml`)

| Threshold | Value | Meaning |
|-----------|-------|---------|
| CRITICAL_SOC | 20% | Hard discharge floor → low-SoC block, equipment fault |
| LOW_SOC | 30% | Low-battery warning, de-prefer battery |
| GEN_STOP_SOC | 80% | Generator hysteresis upper bound (stop charging) |

## power_source decision logic (ground truth)

Priority of cheapest SAFE source at each timestamp:
1. **solar** if solar_power_kw ≥ load (free once generating).
2. else **grid** if grid stable — but **battery** is peak-shaved during peak
   tariff when SoC > 55% (stored off-peak/solar energy is cheaper than peak grid).
3. else (grid down/unstable, solar insufficient) island mode:
   - **generator** if latched & available & SoC < 80% (hysteresis),
   - else **battery** if SoC > 30%,
   - else **generator** if available (latch on),
   - else **battery** as forced emergency fallback.

Manual-override rows (~1%) intentionally deviate to a different *safe* source so
the rule engine can flag override conditions.

## equipment_status derivation (priority ordered)

`fault` if: stale timestamp, SoC ≤ 20%, battery temp > 45 °C, or generator fault.
`warning` if: SoC ≤ 30%, fuel < 15%, grid unstable, or frequent switching (≥3
source changes in a 4-sample window).
`ok` otherwise.

## Injected safety/fallback scenarios (Section 7 mapping)

| Scenario | Coverage | Injection mechanism |
|----------|----------|---------------------|
| Low battery SoC block (24 V cutoff) | ~3.9% | Deep-discharge windows (grid outage + generator lockout) on SITE_003 |
| Stale / missing timestamp | ~2.0% | ~2% rows repeat the previous timestamp |
| Grid instability | ~19% | Outage, flap, and sag/swell (voltage & frequency deviation) |
| Low generator fuel | ~14% | Low starting reserve + long refuel interval on SITE_003 |
| Frequent switching | ~5.5% | Grid-flap windows toggling availability each tick |
| Manual override | ~1.0% | Random safe-source deviation from ground-truth label |

## Self-validation (run at generation time, all passing)

- No solar power/irradiance at night (06:00–18:00 daylight window).
- SoC within 0–100; battery_voltage within 20.0–29.2 V and on-curve (±0.35 V).
- No negative kW on load/solar/grid/generator/energy fields.
- \|battery_current\| ≤ 150 A (C-rate).
- Generator output & fuel burn only while running.
- No grid power while grid unavailable.
- tariff_type & electricity_price consistent with the emitted timestamp hour.
- Fuel monotonic down except on scheduled refuel ticks.
- All six stress scenarios present at target coverage.
